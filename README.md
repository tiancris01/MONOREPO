# EPAM Technical Interview - Flutter Monorepo

A Flutter monorepo showcasing design system architecture and modern development practices.

## Structure

- `packages/ds_fake_store_api/` - Design system package with atomic design components
- `apps/fake_store_api_app/` - Sample application using the design system

## Features

- ✅ Melos workspace management
- ✅ Git hooks for code quality
- ✅ Comprehensive analysis options
- ✅ Automated formatting and linting
- ✅ Weather-themed design tokens

## Development

```bash
# Bootstrap the workspace
melos bootstrap

# Run analysis
melos analyze

# Format code
melos format

# Run tests
melos test
```

## Code Quality

This project enforces high code quality standards through:

- Pre-push git hooks
- Comprehensive Flutter analysis
- Automated code formatting
- SOLID principles enforcement
